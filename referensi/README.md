# Referensi (bukan bagian aplikasi)

`prototipe-ews/` adalah gambaran kasar EWS yang dibuat lebih dulu (Laravel).
- Hanya untuk DIBACA. Jangan dijalankan, jangan disalin mentah ke `app/`.
- Berkas rahasia (`.env`), basis data, log, dan cache sengaja tidak disertakan.
- Daftar hal yang harus diperbaiki: `PLAN.md` bagian "Catatan dari prototipe".
- Folder ini dikecualikan dari Pint (`pint.json`) dan tidak dimuat autoload.
